# How game.js Works

game.js generates a fate written by Tracery (using a couple of the palm slider values), shows GAME OVER, and then reveals the story. Everything lives inside one block.

## Loading

As soon as the page opens, the script starts fetching everything it will need so nothing stalls when the player presses play. It requests the two name lists (firstNames.json and fantasyNames.json), and it builds the grammar. The grammar comes from two main files in assets/grammar. fate.json holds the fate templates, and corpora.json is a manifest that maps each Tracery rule name to a word list in assets/corpora. The script fetches each corpus file once, even when several rules point to the same file, then pulls out the right list. A corpus file can be a plain list or an object that keeps the list under the rule's name, and a manifest entry can name a field to pluck from each item when the list holds objects. The fate templates and all the word lists are merged into a single raw grammar and kept ready as a promise.

The three game over sounds are also loaded up front with preloading turned on, so the first one plays without a delay.

## Names

When the player hits the random button, or presses play with the name field empty, the script picks a name. It first chooses between the ordinary list and the fantasy list with equal odds, then picks a name from that list. I haven't decided if I will keep the fantasy names, they're funny but the style of the text corpus over time has started getting a decided 19th century style that the fantasy names list confounds a little bit. I'm also not sure if it's a good idea to auto pick a name when the name field is left empty. It might be funny to say "you were born without a name..."

## Reading the Hand

On play, the script looks at every range input whose id ends in "-range". For each one it works out how far along the slider sits, from zero to one, and records whether it is at least halfway. These are stored by line name, so "line-of-the-head-range" becomes a flag called "line-of-the-head" that is either long or short.

## Choosing a Fate

Only the line of the head and the line of the heart decide the fate right now. The pair function turns two flags into a position from zero to three, in the order both long, head long only, heart long only, both short. That position picks a slot in the fates list. Both long gives fateHubris, a long head with a short heart gives fateApprentice, a long heart with a short head gives fateDuel, and both short gives either fateCrime or fateNeglect at random. Adding another template to any slot is enough to put it into rotation.

## Writing the Fate

generateFate builds a new Tracery grammar from the raw grammar plus a name rule holding the character's name, adds standard English modifiers, and expands the chosen template. Because the templates contain HTML for blockquotes, the result goes into the page as HTML, so the typed name is escaped first to keep anything the player types from being read as markup. The chosen template's name is also added as a class on the story text (for example "is-fateDuel") so each kind of fate could be styled on its own if I wanted.

## Game Over and the Story

After the text is written, the story is unhidden but kept invisible with css, the GAME OVER element is shown, and one of the three stinger sounds plays at random. When the GAME OVER animation ends, that element hides itself and the story fades in by gaining the "is-visible" class.

## Trying Again

The try again button hides the story, clears the name field, and puts each slider back to its default value. It then fires an input event on each slider so slider.js redraws the lines on the hand and the readouts to match. The stored name and line flags are cleared too. I wonder if I should actually be clearing the sliders, since leaving them would help the player experiment and discover how the sliders connect to the output text. Ultimately that probably isn't that important to enjoying the sketch. The strength as I see it comes from the immediate game over with sound, the mad-libs humor and variation in the story text. It feels done now other than polishing the text and lists and adding a little more variation.
